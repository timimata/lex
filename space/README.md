# Lex

Perguntas sobre o Código do Trabalho português, respondidas só com base nos artigos em vigor na
data escolhida, cada afirmação com o artigo que a apoia. Quando os artigos não chegam, o Lex diz
que não sabe.

O Lex é também um benchmark aberto: a página "Resultados" mostra quantas vezes cada sistema
acerta num conjunto de teste que nunca serviu para o afinar.

Os textos consolidados não têm valor legal: só faz fé a publicação no Diário da República. O Lex
não é aconselhamento jurídico.
