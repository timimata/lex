# Superseded test runs

These two runs used the Phase 0 split, a hash of the item id. The Phase 2 double check found dev
items that give away test answers under that split, and the split became grouped by main article
([ADR 0009](../../../docs/decisions/0009-split-by-main-article.md)). The runs are kept as they
were measured and are not reported anywhere; the current test runs are one level up.
