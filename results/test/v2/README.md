# Benchmark v2 runs

Test runs of 2026-10-02 and 2026-10-06 on benchmark v2: 97 test items (80 answerable, 17
unanswerable), 9 of them on tenancy. On 2026-10-06 twenty tenancy items brought the benchmark to
v3 (201 items, 109 in test), and the systems are measured again on it. Kept for the record; the
leaderboard reads only the runs in `results/test/`, on the current benchmark, so numbers on
different questions are never compared. The README and the roadmap report these v2 numbers until
v3's are measured.
