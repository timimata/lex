# Security

Lex is a research project: an open benchmark, the code that measures systems on it, and a public
demo (https://lex-beryl.vercel.app). Please report a vulnerability privately, through GitHub's
"Report a vulnerability" on the repository's Security tab, not in a public issue.

What counts, for example: a way to make the demo spend its model quota beyond its limits, to read
or write what it should not, or to inject content into its pages; a secret in the repository; a
way to recover the private test split's items from anything published. Answers that are wrong
about the law are not security issues: open an ordinary issue, and remember that Lex is not legal
advice.

You will get an answer within a week. The demo runs on free tiers and holds no personal data
beyond the questions visitors type, which go to Google's Gemini API (ADR 0016, amended).
